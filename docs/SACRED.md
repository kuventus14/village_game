# 성당 · 사찰 · 교회 (2026-11-03 사용자 요청, 같은 날 그림 대응 정정)

사용자가 그림 3장을 줬다(`docs/ref/`, 파일 이름은 그대로 둠). **정정된 대응: 그림 1 = 교회, 그림 2 = 사찰, 그림 3 = 성당.**
조작은 지금 마을과 같다(WASD/조이스틱으로 걷고, 가까이 가면 안내가 뜨고 버튼/E 키). 건물은 전부 **들어갈 수 있다.**

## 3배 확대 + 마을 넓히기 (2026-11-03 두 번째 요청: "3배는 크게", "딱 봤을 때 웅장하게")

- **설계도 → 실제 변환**: 세 단지는 `world.js` 의 설계도 좌표(`SACRED_DESIGN` = 원래 1배 크기 `B`·`P`·`TY`)로 정의하고, `XF[k]` 로 **3배 확대 + 회전**해서 실제 마을에 놓는다. `toWorld(k,x,z)`·`toDesign(k,X,Z)`.
  - 성당: c0 (-36.5,-7.5) → c1 (-92, 5), 90° 돌려 **동쪽(광장)을 봄**. 교회: c0 (37,-8.5) → c1 (93.5, 5), -90° 돌려 **서쪽(광장)을 봄**. 사찰: c0 (270,-108) → c1 (346,-194), 회전 없음.
  - 렌더링(`sacred.js`)은 설계도 좌표로 짓고 그룹을 같은 변환(3배·회전·이동)으로 놓는다. 충돌·발 높이는 실제 좌표를 설계도로 바꿔 설계도 충돌 목록(반지름 1/3)으로 계산 → 그림과 충돌이 항상 일치.
  - 사람 크기 그대로: 아바타·기존 마을, 그리고 사람이 쓰는 가구(의자·방석 등). 3배: 건물·배경 구조물·분수. 큰길 가로등·벤치·벚나무는 사람 크기 그대로(그림에서도 사람 크기)이고 줄을 지어 원근을 만든다.
- **마을 울타리**: 서·동으로만 넓힘 `BX = 120`(x ±120), `BZ = 44`(z 는 그대로). `BOUND`(44)는 예전 마을 반쪽 크기로 남겨 예전 나무·꽃 생성 순서를 그대로 둠. 기존 건물·가구·놀이터·연못·카지노·집 좌표와 `SEATS` 앞번호는 그대로이고, 새 벤치(`BENCHES2`)·긴 의자는 번호 맨 뒤에 붙는다.
- **큰길(정면 축)**: 광장 → 성당 `AVENUES.cathedral` [-51..-11, z 1.6..8.4], 광장 → 교회 [11..49]. 길 가운데 z=5 = 두 건물 문 가운데 축. 양옆에 가로등·벚나무·낮은 꽃 화단을 줄지어 둠.

## 데이터 약속 (`public/world.js`, 서버·브라우저·시험이 같이 씀) — 좌표는 모두 **실제(3배) 좌표**, 설계도 값은 `SACRED_DESIGN`

```js
SACRED = { cathedral: { name: '성당', icon: '⛪' }, temple: { name: '사찰', icon: '🛕' }, church: { name: '교회', icon: '⛪' } };
PLACE.cathedral / temple / church / trail('🌲 숲길')
placeOf(x, z)   // 건물 안 → 그 id, 사찰 마당(법당 밖)도 'temple', 숲길 위 'trail', 그 밖 'town'
BUILDINGS.cathedral / church / temple  // 실제 크기 (fy = 바닥 높이 2.7~3.0)
SACRED_DESIGN { B, P, TY }  // 설계도(1배) 좌표. SACRED_PROPS = SACRED_DESIGN.P
XF, toWorld(k, x, z), toDesign(k, X, Z)  // 설계도 ↔ 실제 (3배 + 회전)
SACRED_BOXES, AVENUES, FACADES, BX, BZ, inTown, GATE, GATE_PATH, TRAIL, trailNear, STREAM, TEMPLE_YARD, inYard
floorY(x, z)    // 발 딛는 높이 (최대 3.0). game.js 가 서 있는 높이(gy)에 더함
SPOTS = [ { id, bld, kind, x, z, ry, y } ]  // id = 배열 순서, ry = 바라보는 방향(0 = +z, 건물 회전 반영), y = 발 높이
SEATS  // kind 'pew' (사람 크기, h 0.45). 앉으면 상태 pray ('🙏 기도 중'), 말풍선 '🙏 기도하는 중'
pewSeats(p)     // 설계도의 긴 의자 한 줄 → 자리 좌표들
STATUS.pray = ['🙏', '기도 중'], SIT_STATUS.pew = 'pray', SIT_TEXT.pew = '🙏 기도하는 중'
```

  - 천장: 붉은 서까래 박공 천장.
  - 등: 분홍 연꽃 등(큰 것 4, 작은 것 8, 금 술), 서 있는 나무 등롱 8.
  - 방석: 주황·올리브·연어·노랑이 섞인 격자, 가운데 통로 양옆 5열×10줄 = 100개. 기둥 바깥에 보라 염주 방석이 따로 있습니다.
  - 불단 쪽: 3단 불단, 금빛 감실, 웃는 금불상(오른손 들어 올림), 귤 공양상 2, 향로, 연꽃 화병, 연꽃 등대 2, 촛불 등롱.
- **바닥 높이 = 발 높이**: 법당 마루는 발 높이(3.0m)에 맞췄습니다. 이전에는 0.39m 높게 그려져 아바타가 묻혀 보였습니다. 성당·교회도 바닥과 발 높이가 같습니다(2.7, 제단 구역·무대 3.0).
- 밤에는 실내 랜턴·연등·등롱이 `nightGlow` 로 더 환해집니다.
- **실내 조명 (성당·교회·사찰 안에서만)**: `atmosphere.js` 의 `IN_WARM`. 시간과 상관없이 늘 '따뜻한 노을 실내' 톤입니다.
  - 반사광: 위는 살구, 아래는 분홍.
  - 주 조명: 주황 해빛 1.3.
  - 보조광: 분홍 0.55.
  - 블룸 0.5: 랜턴·창이 번져 보입니다.
  - 카페·회사·카지노는 예전 낮 조명(`IN_DAY`) 그대로이고, 밖 풍경·광장도 그대로입니다.
  - 밤에는 실내 랜턴·연등·등롱 발광이 1.7배가 되고, 창 유리는 밤하늘처럼 어두워집니다.
- 창: 성당 실내 창은 연한 분홍·노랑 스테인드글라스, 사찰 꽃살창 너머는 노을·벚나무 그림판, 교회 아치창은 분홍빛 유리입니다.
- 실내 카메라: 성당·교회·사찰 안에선 시선을 2.6m 위로 들어 높은 천장이 보이게 합니다. 행동 중엔 0.4m(기능 작업 값 유지)이고, 카메라가 벽에 막혀 가까워지면 덜 듭니다.
- 실내에서 카메라가 벽에 막혀 가까워지면 시선을 덜 들어 올립니다(`game.js`).

## 겉모습 그림 맞추기 (r6~r8)

- **사찰**: 마당을 120×120 에서 90×84(설계도 30×28)로 줄였습니다. 구내 전체는 북쪽으로 36m 옮겨서(`XF.temple.c1` = (346,-158)) 숲길 끝인 마당 입구는 (346,-134) 그대로입니다.
  - 축대 높이는 실제 6m입니다. 걷는 높이 제한을 6m로 완화했고, 18단 큰 돌계단은 걸음당 0.3m 이하로 오릅니다.
  - 배치는 그림처럼 바꿨습니다: 석탑(0.7배)은 계단 앞 가운데, 연꽃 석등은 계단 아래 한 쌍 + 앞쪽 한 쌍, 범종각은 오른쪽 앞, 전각은 왼쪽 앞·오른쪽 뒤에 둘입니다.
  - 일주문·천왕문은 그림에 없어서 뺐습니다.
  - 대웅전 지붕을 키우고 짙은 회보라 기와로 바꿨습니다. 뒤에 숲 언덕을 넣었습니다.
- **교회**: 날개채를 2층으로 했습니다(1층 아치 회랑, 2층 노란 창 줄, 회랑 위 작은 처마). 앞면은 정면에 가깝게 당겼습니다.
- **성당**: 본당을 앞으로 2(실제 6m) 늘려 3/4 구도에서 옆면 창 줄이 보이게 했습니다. 정면 박공 가장자리에 크림 돌 장식을 넣었고, 성모상은 계단 오른쪽 앞, 분수는 왼쪽 앞에 둡니다.
